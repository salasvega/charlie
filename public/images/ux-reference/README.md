# Illustrations de l’Accueil

Ces trois PNG ont été reconstruits par génération d’image, en utilisant la maquette officielle fournie dans la conversation comme référence visuelle :

- `classroom-hero.png` : adolescente brune en hoodie violet dans un bureau éclairé en bleu et en lumière chaude, ordinateur au symbole C.
- `valley.png` : paysage de montagnes mauves, lac et forêt, pour la sidebar et le mode concentration.
- `avatars.png` : bande de quatre portraits (adolescente, robot, jeune homme à lunettes, chat).

Ce ne sont pas les fichiers sources originaux de la maquette : les différences de cadrage et de détail sont signalées dans `docs/ux/REALIGNEMENT.md`. Ils doivent être remplacés par les exports graphiques officiels quand ils seront disponibles. Aucun asset de stock sans rapport avec le projet n’est utilisé.

La police Nunito Sans est fournie localement par `@fontsource/nunito-sans`, sous licence OFL incluse dans le paquet. Aucun appel distant de police n’est effectué.
